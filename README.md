# Geipel Website Relaunch

Neuentwicklung der Unternehmenswebsite für **Sicherheitsdienst & Detektei Geipel**.

## Ziel

- vorhandene Inhalte erhalten
- übersichtlichere Informationsarchitektur
- moderne responsive Website für Desktop, Tablet und Smartphone
- deutsche Master-Version
- englische Sprachversion
- nachvollziehbare Versionsverwaltung über Git

## Aktueller Stand

**Phase 2: Sitemap & Informationsarchitektur – gestartet**

Phase 1 (Bestandsaufnahme) ist ausreichend gesichert, um mit der neuen Struktur zu arbeiten.
Fehlende historische Assets können später ergänzt werden.
