# Phase 2 — Strukturentscheidungen

## Bereits gesetzt

- Deutsch ist die Master-Version.
- Englisch folgt der freigegebenen deutschen Fassung.
- eine responsive Website statt separater Desktop-/Mobilversionen
- Leistungen werden deutlich sichtbarer strukturiert
- Detektei bleibt als Obergruppe erhalten
- Rechtliches wandert in den Footer
- historische Inhalte bleiben im Archiv unverändert
- neue Texte und Alttexte werden nicht vermischt
- das bereitgestellte Wappen wird als offizielles Projekt-Asset geführt

## Noch offen / später entscheiden

- endgültiger Header-Aufbau
- genaue Gestaltung des Leistungsmenüs
- ob „Über uns“ als eigene Seite oder ausführlicher Startseitenabschnitt umgesetzt wird
- Umfang des Karrierebereichs
- externe Partnerlinks im Footer
- Kontaktformular ja/nein
- Kartenintegration
- Social-Media-Integration
- finales Farbsystem und Typografie

---

## Wireframe-Entscheidungen Startseite v0.1

- Sticky Header
- Wappen links im Header
- primäre Hauptnavigation horizontal auf Desktop
- mobiles Klappmenü
- Hero mit zwei klaren CTAs
- keine lange Textwand im Hero
- Leistungsübersicht direkt nach Hero
- Detektei bleibt als Obergruppe sichtbar
- Unternehmensgrundsätze erhalten eigene Darstellung
- Karriere wird als eigener Startseitenabschnitt sichtbar
- Kontakt-CTA unmittelbar vor Footer
- rechtliche Links ausschließlich im Footer
