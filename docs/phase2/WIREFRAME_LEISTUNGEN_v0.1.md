# Phase 2 — Wireframe Leistungsübersicht v0.1

## Ziel

Die Leistungsübersicht soll alle historisch belegten Leistungsbereiche schnell erfassbar machen.

## Struktur

1. Seitenkopf / kurze Einleitung
2. Detektei als hervorgehobene Obergruppe
3. Veranstaltungsschutz / Einlasskontrolle
4. Objektschutz / Revierfahrten
5. Personenschutz
6. Orientierungshilfe
7. Kontakt-CTA
8. Footer

## Wichtige Entscheidung

Die Detektei wird bewusst als Obergruppe dargestellt, weil dies bereits der historischen Navigation entspricht.

Untergeordnet:
- Warenhausdetektiv / Doorman
- Observation & Beobachtung

## Noch offen

- endgültige Texte
- Icons
- Bildmaterial
- Priorisierung der Karten
- mögliche zusätzliche bestätigte Leistungen
