# Phase 2 — Wireframe Muster-Leistungsseite v0.1

**Muster:** Warenhausdetektiv / Doorman

## Ziel

Alle einzelnen Leistungsseiten folgen später demselben Grundschema.

## Aufbau

1. Breadcrumb
2. Leistungstitel
3. kurze Einleitung
4. primärer CTA
5. Bild-/Medienfläche
6. seitliche Leistungsnavigation
7. gegliederter Haupttext
8. redaktioneller / fachlicher Prüfhinweis
9. verwandte Leistungen
10. Kontakt-CTA
11. Footer

## Vorteil

Der Besucher erkennt auf jeder Leistungsseite sofort:
- wo er sich befindet
- worum es geht
- welche verwandten Leistungen existieren
- wie er Kontakt aufnehmen kann

## Redaktionsregel

Der alte Originaltext wird später nicht einfach ersetzt, sondern:
1. archiviert
2. sprachlich modernisiert
3. fachlich geprüft
4. mit dem Auftraggeber freigegeben
