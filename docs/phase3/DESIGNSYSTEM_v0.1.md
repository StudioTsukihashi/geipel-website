# Phase 3 — Designsystem v0.1

**Projekt:** Sicherheitsdienst & Detektei Geipel  
**Status:** Arbeitsfassung / Designrichtung 1  
**Grundlage:** Original-Wappen + intern freigegebene Informationsarchitektur aus Phase 2

## Designziel

Die neue Website soll:

- seriös und zuverlässig wirken
- Sicherheit vermitteln, ohne martialisch zu wirken
- moderner als die frühere Website sein
- auf Desktop und Smartphone sehr gut lesbar bleiben
- das vorhandene Wappen sichtbar respektieren
- keine übertriebene „Security-Tactical“-Optik verwenden

## Visuelle Leitidee

**Modern Security / klare Autorität**

Das Wappen liefert die historischen Markenfarben Blau, Gelb, Schwarz und Weiß.
Für die Website werden diese Farben kontrolliert eingesetzt:

- Dunkles Anthrazit = Grundfläche / Sicherheit / Ruhe
- Geipel-Blau = primäre Marken- und Aktionsfarbe
- Geipel-Gelb = gezielter Akzent
- Weiß = Lesbarkeit und Luft
- neutrale Grautöne = Flächen, Linien, Sekundärinformationen

Gelb wird nicht großflächig verwendet, sondern für:
- kleine Marker
- aktive Zustände
- Eyebrows
- einzelne Hervorhebungen
- Fokuszustände

## Stil

- klare geometrische Flächen
- große Überschriften
- deutliche Hierarchie
- keine unnötigen Verzierungen
- dezente Übergänge
- moderate Eckenradien
- Schatten nur sparsam
- robuste, gut lesbare UI

## Barrierefreiheit

Kontrast und Fokuszustände werden von Anfang an berücksichtigt.
Die Primärfarbe #035CDD erreicht auf Weiß ausreichenden Kontrast für normalen Text.
Gelb wird bevorzugt mit sehr dunklem Text kombiniert.
