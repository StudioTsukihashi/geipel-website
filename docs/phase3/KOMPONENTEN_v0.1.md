# Phase 3 — Komponenten v0.1

## Header
- dunkle Grundfläche
- Original-Wappen links
- Firmenname daneben
- Hauptnavigation rechts
- aktive Seite mit Blau-/Gelb-Akzent
- mobile Navigation als Menü

## Buttons

### Primary
Blau, weißer Text.

### Secondary
Transparent bzw. dunkel mit sichtbarem Rahmen.

### Accent
Gelb mit dunklem Text, nur für besondere Aktionen.

## Leistungskarten
- klare Überschrift
- kurze Zusammenfassung
- kleine Kategorie
- Pfeil / Link
- Hover nur dezent

## Informationskarten
Für:
- Unternehmensgrundsätze
- Kontakt
- Karrieredaten
- redaktionelle Hinweise

## Formulare
- sichtbare Labels
- große Eingabefelder
- deutlicher Fokuszustand
- keine Placeholder-only Formulare
- Fehlermeldungen später direkt am Feld

## Abstände
8-Pixel-Raster als Basis:
8 / 16 / 24 / 32 / 48 / 64 / 80 / 96 px
