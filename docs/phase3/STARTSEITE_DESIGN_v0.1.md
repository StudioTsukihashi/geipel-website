# Phase 3 — Startseite Designentwurf v0.1

**Status:** Arbeitsfassung / erste Anwendung des freigegebenen Designsystems

## Zweck

Der zuvor freigegebene Startseiten-Wireframe wurde erstmals in ein echtes visuelles Layout
überführt.

## Eingesetzte Elemente

- Original-Wappen
- Geipel Blue `#035CDD`
- Geipel Yellow `#FBFA00`
- dunkles Anthrazit als Hero-/Footer-Basis
- helle Inhaltsflächen
- responsive Navigation
- Hero ohne Stockfoto
- grafisches Markenpanel mit Wappen
- Leistungs-Karten
- Detektei-Hervorhebung
- Unternehmensgrundsätze
- Karrierebereich
- Kontakt-CTA
- bestätigte externe Footer-Links

## Bewusste Entscheidungen

### Kein Stockfoto im Hero

Aktuell fehlen freigegebene Firmenbilder. Statt eines beliebigen Sicherheits-Stockfotos nutzt
der Entwurf daher das Original-Wappen als Markenfokus.

### Texte

Die Texte sind teilweise Design-/Arbeitskopie. Die finale redaktionelle Fassung entsteht erst
in Phase 4. Historische Aussagen werden nicht stillschweigend als neue Fakten erweitert.

### Kontakt

Keine aktuelle Telefonnummer oder E-Mail wurde im Design fest eingebaut, da deren finale
Veröffentlichungsfreigabe noch aussteht.

### Kontaktformular

Das offene Kontaktformular aus Phase 2 wird im Startseiten-Entwurf nicht vorausgesetzt.
