# Phase 3 — Typografie v0.1

## Grundsatz

Für die erste Designsystem-Version wird bewusst kein externer Webfont geladen.
Damit bleibt die Vorschau unabhängig von Drittanbietern und schnell.

## Font Stack

```css
font-family:
  "Segoe UI Variable",
  "Segoe UI",
  system-ui,
  -apple-system,
  BlinkMacSystemFont,
  Arial,
  sans-serif;
```

## Größen

| Stil | Desktop | Mobil |
|---|---:|---:|
| Display / Hero | 64–76 px | 40–48 px |
| H1 | 52–64 px | 38–44 px |
| H2 | 36–44 px | 30–34 px |
| H3 | 22–26 px | 21–24 px |
| Lead | 19–21 px | 18 px |
| Body | 16–18 px | 16 px |
| Small | 13–14 px | 13–14 px |

## Typografische Regeln

- große Headlines kurz halten
- Fließtext auf ca. 65–75 Zeichen pro Zeile begrenzen
- keine komplett großgeschriebenen langen Überschriften
- Großbuchstaben nur bei kleinen Labels / Eyebrows
- Zeilenhöhe Body ca. 1.55–1.7
